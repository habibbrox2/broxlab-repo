# Fix Header Notification and User Dropdown Visibility

## Problem Analysis

The header notification body and user dropdown menu are not displaying properly, particularly in dark mode. The issue stems from missing dark mode CSS styles for the notification dropdown, causing it to retain light mode backgrounds (white) that blend with dark backgrounds or create poor contrast.

## Key Issues Identified

1. **Missing Dark Mode Styles for Notification Dropdown**: The `.brox-notification-dropdown` lacks dark mode overrides in `7-dark-mode.css`, unlike the user dropdown which has proper styling.
2. **Header Styling Inconsistency**: The notification dropdown header (`brox-notification-dropdown-header`) has dark mode styles only for mobile, not desktop.
3. **Potential Contrast Issues**: In dark mode, unstyled elements may have poor visibility.

## Proposed Solution

Update `public_html/assets/css/7-dark-mode.css` to add comprehensive dark mode styles for the notification dropdown, ensuring proper visibility and styling across all themes.

### Specific Changes

1. Add dark mode background, border, and shadow for `.brox-notification-dropdown`
2. Style the notification dropdown header for dark mode on desktop
3. Ensure header text color is set for dark mode
4. Verify scrollbar styling in dark mode
5. Update any other missing styles to match the user dropdown's dark mode appearance

### Files to Modify

- `public_html/assets/css/7-dark-mode.css`: Add missing dark mode selectors for notification dropdown elements

### Testing

- Ensure proper contrast and readability
- Verify on mobile and desktop breakpoints
- Check dropdown positioning and z-index
