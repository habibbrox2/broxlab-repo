# SEO Checklist for New Content

Quick reference for creating SEO-optimized articles and pages on BroxLab.

## Before Publishing

### ✅ Content Fundamentals
- [ ] Content is 1500+ words (for articles)
- [ ] Original, unique content (not copied from other sources)
- [ ] Spell-checked and grammar-reviewed
- [ ] Includes at least 2-3 credible sources/citations
- [ ] Author information complete and accurate

### ✅ Title & Meta
- [ ] **Page Title**: 50-60 characters, includes primary keyword
- [ ] **Meta Description**: 150-160 characters, compelling CTA, unique
- [ ] **Slug**: Descriptive, lowercase, hyphens only (no underscores)
- [ ] **Canonical URL**: Set if needed (usually automatic)

### ✅ Heading Structure
- [ ] One H1 per page (matches primary topic)
- [ ] H2-H3 headings follow logical hierarchy
- [ ] No skipped heading levels (e.g., H1 → H3)
- [ ] Headings include keywords naturally
- [ ] At least 3 subheadings

### ✅ Images & Media
- [ ] **Images**: High quality, relevant to content
- [ ] **Alt Text**: Every image has descriptive alt text (see guide below)
- [ ] **File Names**: Descriptive, hyphenated (e.g., iphone-15-camera.jpg)
- [ ] **Size**: Optimized, under 200KB per image
- [ ] **Format**: WebP preferred, JPG/PNG as fallback

### ✅ Internal Linking
- [ ] At least 3-5 internal links
- [ ] Links use descriptive anchor text
- [ ] Links point to relevant pages
- [ ] Links open in same tab (unless external)

### ✅ Schema Markup
- [ ] Article schema auto-generated by template
- [ ] Categories/tags assigned for keyword context
- [ ] Featured image set
- [ ] Author name entered
- [ ] Publication date correct

### ✅ Categories & Tags
- [ ] Primary category selected (max 3)
- [ ] 3-5 relevant tags added
- [ ] Tags are lowercase, consistent
- [ ] No duplicate tags

## Image Alt Text Quick Reference

### Device Review Article
```
[Brand] [Model] - [Key distinguishing feature]

Examples:
- "iPhone 15 Pro - Premium smartphone with titanium design"
- "Samsung Galaxy S24 Ultra - flagship with 200MP camera"
- "Google Pixel 8 Pro - AI-powered smartphone features"
```

### Feature/Specification Image
```
[Device Name] [Feature Name] - [What's shown in image]

Examples:
- "iPhone 15 Pro camera system - showing lens array and macro mode"
- "Samsung S24 display - 6.8-inch Dynamic AMOLED screen"
- "Google Pixel AI features - Magic Eraser interface"
```

### Comparison/Chart
```
[Chart Type] comparing [Item A] and [Item B] - [Key difference]

Examples:
- "Performance benchmark chart comparing iPhone 15 Pro vs Pixel 8"
- "Camera comparison showing iPhone macro vs standard mode"
- "Battery life comparison table - top smartphones 2024"
```

### Screenshot/UI
```
[App/Device] [Feature] - [What's visible in screenshot]

Examples:
- "Gmail interface on Android showing conversation threads"
- "iOS Camera app macro mode toggle"
- "Samsung One UI settings menu"
```

## Meta Description Templates

### Article/Review
```
[Product] [review] - [key feature]. [Quick fact]. 
Expert analysis, specs, and [comparison/rating].

Length: ~155-160 characters

Example:
"iPhone 15 Pro review - flagship with A17 Pro chip. 
Expert camera analysis, detailed specs, and comparison with Pixel 8 Pro."
```

### How-To/Guide
```
Learn [how to]. Step-by-step guide for [goal]. 
[Additional benefit]. Tested and verified.

Example:
"Learn how to improve iPhone battery life. Step-by-step guide 
to extend battery, optimize settings, and reduce power drain."
```

### Comparison
```
Compare [Item A] vs [Item B]. See [key differences]. 
Full specs, pricing, and [verdict/recommendation].

Example:
"Compare iPhone 15 Pro vs Samsung S24 Ultra. See camera, 
performance, and price differences. Full specs and our pick."
```

## SEO Optimization Checklist

### Content Quality (E-E-A-T)
- [ ] Author expertise is clear
- [ ] Experience shared where relevant
- [ ] Links to authoritative sources
- [ ] Content is trustworthy and accurate
- [ ] Updated/reviewed date shown

### Keyword Optimization
- [ ] Primary keyword in title (ideally first)
- [ ] Primary keyword in meta description
- [ ] Primary keyword in first 100 words
- [ ] Keywords naturally integrated (no stuffing)
- [ ] Related keywords mentioned 2-3 times
- [ ] LSI keywords included (synonyms/variations)

### User Experience
- [ ] Content is scannable (short paragraphs)
- [ ] Bullet points/lists where appropriate
- [ ] Clear call-to-action (related article link)
- [ ] Content easy to read (good fonts, spacing)
- [ ] Mobile-friendly formatting

### Technical
- [ ] No broken links (internal or external)
- [ ] Images load quickly
- [ ] Page loads in under 3 seconds
- [ ] Mobile responsive tested
- [ ] No spelling/grammar errors

## Publishing Checklist

### Before Click "Publish"
- [ ] Proofread entire article (2x minimum)
- [ ] Test all links work (click each one)
- [ ] Preview on mobile device
- [ ] Featured image displays correctly
- [ ] Meta description displays properly
- [ ] All images have alt text
- [ ] Categories and tags assigned

### After Publishing
- [ ] View published page in browser
- [ ] Check page load speed
- [ ] Verify schema markup (use Rich Results Test)
- [ ] Share on social media (with snippet)
- [ ] Update internal links if relevant
- [ ] Ping XML sitemap (usually automatic)

## Common Mistakes to Avoid

❌ **Keyword Stuffing**
- Don't repeat keyword 10+ times
- Write naturally for humans first
- Use related keywords and synonyms

❌ **Thin Content**
- Don't publish anything under 1500 words
- Avoid repeating same point multiple times
- Add real value and unique insights

❌ **Poor Alt Text**
- Don't use "image," "photo," or generic descriptions
- Don't stuff keywords into alt text
- Make it descriptive and useful

❌ **Bad Meta Descriptions**
- Don't duplicate descriptions across pages
- Don't forget to update when content changes
- Don't make them too long (over 160 chars)

❌ **Broken Links**
- Don't link to dead/404 pages
- Don't use outdated URLs
- Test all links before publishing

❌ **Missing Images**
- Don't publish without featured image
- Don't use low-quality images
- Add relevant images throughout article

## Tools to Use

### Before Publishing
1. **Spell Check**: Grammarly or browser extension
2. **Link Checker**: Check all links work
3. **Mobile Preview**: Browser dev tools (F12)
4. **Plagiarism Check**: Copyscape or similar

### After Publishing
1. **Rich Results Test**: https://search.google.com/test/rich-results
2. **Mobile-Friendly Test**: https://search.google.com/test/mobile-friendly
3. **PageSpeed Insights**: https://pagespeed.web.dev/
4. **Accessibility Check**: WAVE browser extension

## Quick URL Structure

- ✅ Good: `/posts/iphone-15-pro-review`
- ✅ Good: `/reviews/samsung-galaxy-s24-comparison`
- ❌ Bad: `/posts/123` (no description)
- ❌ Bad: `/article_iphone_15` (underscores, not hyphens)
- ❌ Bad: `/posts/iPhone15ProReview` (mixed case)

---

## Publication Date & Updates

- **New Content**: Publish with actual date
- **Updated Content**: Update publication date to today
- **Minor Fixes**: Don't update date (spelling, links)
- **Content Refresh**: Update publication date, add update note

Example update note:
```
**Updated April 28, 2026**: Added latest pricing information 
and new performance benchmarks.
```
