Setup
Installation
1
Clone the repository
bash
git clone git@github.com:habibbrox2/broxlab-repo.git broxlab
cd broxlab
2
Install dependencies
bash
# PHP dependencies
composer install

# Node.js dependencies
npm install
3
Configure database & environment
Edit Config/Db.php, Config/Constants.php, and add API keys to .env — Firebase, Telegram, AI providers.
bash
mysql -u <user> -p <database> < Database/schema.sql
4
Set permissions & build assets
bash
chmod -R 755 storage/ public_html/uploads/
npm run build
5
Start local development server
bash
php -S localhost:8000 -t public_html

# Watch assets in a separate terminal
npm run dev
