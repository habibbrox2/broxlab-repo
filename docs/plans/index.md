# Planning Documents Index

## Summary
This folder captures planning artifacts for AI migrations, scraper diagnostics, and source validation work.

## Plan Catalog
- `docs/plans/ai-assistant-nodejs-migration.md` — Migration strategy for moving the AI assistant backend from PHP to Node.js + TypeScript.
- `docs/plans/check-existing-sources.md` — SQL-led investigation into failing scraper sources, job history, and selectors.
- `docs/plans/css-selector-tester.md` — Specifications for the CSS selector tester that validates scraper selectors against live pages.
- `docs/plans/scraper-diagnostic-plan.md` — Step-by-step diagnostic process: analyze sources, logs, selectors, and services.
- `docs/plans/scraper-diagnostic-report.md` — Log analysis report covering error categories, available log APIs, and next steps.
- `docs/plans/scraper-diagnostic-script.md` — Operational script for surfacing active sources, recent failures, and stale entries.
- `docs/plans/scraper-services-test.md` — Testing checklist for individual scraping services (PhpScraper, Panther, Roach, PHP Spider, Advance Scraper).

## Usage
Update this index whenever a new plan is added. Keep plans focused on a single initiative and link back to this file for discoverability.
