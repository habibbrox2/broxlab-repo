# Editor Documentation Index

## Purpose
Catalog of code editor guidance (Claude/Cursor/Windsurf) and shared rules so new editors know where to start.

## Documents
- `docs/editors/rules-base.md` — Shared hard rules, workflow checks, and verification commands.
- `docs/editors/claude.md` — Claude-specific setup tips and workflow reminders.
- `docs/editors/cursor.md` — Cursor guidance and minimal diff expectations.
- `docs/editors/windsurf.md` — Windsurf best practices for controllers, security, and assets.
- `docs/editors/cursor-rules.md` and `docs/editors/windsurf-rules.md` — Quick rule sheets for each editor.
- `docs/editors/kilocode-plan.md` — Vision for the Kilo Code organizational plan.

## Usage
1. Read `docs/editors/rules-base.md` to learn shared expectations.
2. Pick the editor-specific file matching your tool (Claude, Cursor, Windsurf).
3. Keep verification commands handy and link to `docs/index.md` for the broader documentation.
